Creating a smaller set of new features from a larger set.

Principal Component Analysis (PCA): A dimensionality reduction technique that creates a new set of uncorrelated features (principal components) that capture the maximum variance in the data.
Text Data Extraction:
Bag-of-Words (BoW): Represents text as a collection of word counts.
TF-IDF (Term Frequency-Inverse Document Frequency): Like BoW, but gives more weight to words that are important to a specific document rather than common across all documents.
Word Embeddings (e.g., Word2Vec): Represents words as dense vectors in a way that captures their semantic meaning.
Image Feature Extraction: Using pre-trained Convolutional Neural Networks (CNNs) to extract meaningful features from images.
