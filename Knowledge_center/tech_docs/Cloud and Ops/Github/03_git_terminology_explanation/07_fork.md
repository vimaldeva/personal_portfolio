### Fork
A fork is a personal copy of someone else's repository that allows you to freely experiment with changes without affecting the original project. When you fork a repository, you create a copy of it under your own GitHub account. This is particularly useful for contributing to open-source projects, as it enables you to make changes and propose them back to the original repository via pull requests.

When you fork a repository, you can make changes to your copy without impacting the original project. If you want to contribute your changes back to the original repository, you can create a pull request, which allows the maintainers of the original repository to review and potentially merge your changes. Forking is a fundamental part of the collaborative workflow on GitHub, enabling developers to work on projects independently while still contributing to the larger community.

**Key Points**:
- A fork is a copy of a repository that lives on your GitHub account.
- It allows you to make changes without affecting the original repository.
- You can propose changes to the original repository through pull requests.
- Forking is commonly used in open-source projects to facilitate collaboration and contributions.
