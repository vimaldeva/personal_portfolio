### Draft PR
A Draft Pull Request (Draft PR) is a feature in GitHub that allows developers to create a pull request that is not yet ready for review or merging. It serves as a way to indicate that the changes being proposed are still in progress and may not be complete or fully functional.

When you create a draft pull request, it will be marked with a "Draft" label, and reviewers will be able to see that the changes are still being worked on. This can be useful for sharing work-in-progress code with teammates, getting early feedback, or collaborating on changes before they are finalized. 

Draft pull requests can be converted to regular pull requests once the changes are ready for review and merging. This allows developers to signal when their work is complete and ready for feedback from the team.

In summary, a Draft Pull Request is a useful tool for indicating that changes are still in progress and not yet ready for review or merging. It allows developers to share their work with teammates and get early feedback while signaling that the changes are not yet finalized.
