### Clone
**Definition**: The `clone` command is used to create a copy of an existing Git repository. This allows you to have a local version of the repository on your machine, which you can work with independently.

**Usage**: When you clone a repository, Git creates a new directory with the same name as the repository and copies all the files, branches, and history from the remote repository to your local machine. The command typically looks like this:

```bash
git clone <repository-url>
```
