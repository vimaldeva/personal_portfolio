### Secrets prevention feature in Github
GitHub's secrets prevention feature is designed to help developers avoid accidentally committing sensitive information, such as API keys, passwords, or other credentials, to their repositories. This feature scans the code for potential secrets and provides warnings or blocks commits that contain them.

When a developer tries to commit code that includes potential secrets, GitHub will analyze the changes and identify any patterns that resemble sensitive information. If a potential secret is detected, GitHub will display a warning message and may prevent the commit from being completed until the issue is resolved. 



---
How to enable it ?
To enable the secrets prevention feature in GitHub, you can follow these steps: 
1. Go to your GitHub repository.
2. Click on the "Settings" tab at the top of the repository page.
3. In the left sidebar, click on "Security & analysis". 
4. Scroll down to the "Secrets prevention" section and click on "Enable secrets prevention".
5. Once enabled, GitHub will automatically scan your commits for potential secrets and provide warnings or block commits that contain them.
